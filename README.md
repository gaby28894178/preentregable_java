# preentregable_java

📄 README - Sistema de Gestión de Artículos en Java
Este programa en Java es una aplicación de consola que permite gestionar artículos con las siguientes funcionalidades:

Crear artículos nuevos

Consultar artículos por ID

Listar todos los artículos

Modificar artículos existentes

Eliminar artículos

Salir del programa

📦 Archivos involucrados
MenuArticulos.java: contiene la lógica principal del programa.

Clase interna Articulo: modelo de datos para representar un artículo.
